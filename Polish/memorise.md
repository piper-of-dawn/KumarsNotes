# Lecture 1 — Personal Information + Basic Verbs

| English | Polish |
|---|---|
| I | **ja** |
| you | **ty** |
| he | **on** |

# Lecture 2 — Gender + Nominative + `-m, -sz`

## 6. Nominative — Adjective + Noun

| Gender | Question | Adjective Ending | Common Noun Ending | Memory Example |
|---|---|---|---|---|
| Masculine | **jaki?** | `-y / -i` | consonant | **nowy dom** |
| Feminine | **jaka?** | `-a` | `-a / -i` | **nowa książka** |
| Neuter | **jakie?** | `-e / -ie` | `-o, -e, -ę, -um` | **nowe muzeum** |

> [!IMPORTANT] k / g rule
> After **k** or **g**, adjectives usually use:
>
> - masculine → `-i`
> - neuter → `-ie`
>
> **drogi → drogie**  
> **polski → polskie**

> [!TIP] Memory hook
> **Y-A-E**
>
> Masculine → **-y**  
> Feminine → **-a**  
> Neuter → **-e**

## 7. Conjugation — `-m, -sz`

| Person | Typical Ending | `czytać` |
|---|---:|---|

> [!NOTE] Pattern

# Lecture 3 — Nationality + Profession + Instrumental

## 8. `To jest` vs `jest`

| Structure | Case | Example |
|---|---|---|
| **To jest + noun** | Nominative | To jest **Polak**. |
| **On jest + adjective** | Nominative | On jest **sympatyczny**. |
| **On jest + noun** | Instrumental | On jest **Polakiem**. |
| **On jest + adjective + noun** | Instrumental | On jest **sympatycznym Polakiem**. |

> [!IMPORTANT] Core rule
> **To jest → Nominative**
>
> **jest + profession/nationality/noun → Instrumental**

---

## 9. Instrumental Singular — `Kim? Czym?`

|  | Masculine | Feminine | Neuter |
|---|---|---|---|
| Adjective | `-ym / -im` | `-ą` | `-ym / -im` |
| Noun | `-em / -iem` | `-ą` | `-em / -iem` |
| Example | **dobrym nauczycielem** | **dobrą nauczycielką** | **dobrym dzieckiem** |

> [!TIP] Memory hook
> Feminine is easy:
>
> **adjective -ą + noun -ą**
>
> `dobra nauczycielka → dobrą nauczycielką`

# Lecture 4 — Family + Possessives + Accusative

## 13. Age — `rok / lata / lat`

| Number | Form |
|---|---|
| 1 | **rok** |
| 2, 3, 4 | **lata** |
| 5–21 | **lat** |
| 22, 23, 24 | **lata** |
| ending in 2, 3, 4 | **lata** |
| ending in 0, 1, 5, 6, 7, 8, 9 | **lat** |

> Mam **24 lata**.

> **12, 13, 14 → lat**, not *lata*.

## 15. Accusative — `Biernik: Kogo? Co?`

| Gender | Adjective | Noun |
|---|---|---|
| Masculine inanimate | = Nominative | = Nominative |
| Masculine animate | `-ego / -iego` | usually `-a` |
| Feminine | `-ą` | `-ę` |
| Neuter | = Nominative | = Nominative |

### Examples

| Nominative | Accusative |
|---|---|
| nowy komputer | mam **nowy komputer** |
| sympatyczny brat | mam **sympatycznego brata** |
| nowa książka | czytam **nową książkę** |
| małe dziecko | mam **małe dziecko** |

> [!IMPORTANT] Feminine Accusative
> **-a → -ę**
>
> książka → książkę  
> kobieta → kobietę
>
> Adjective:
>
> **-a → -ą**
>
> nowa książka → nową książkę

# Lecture 5 — Hobby + Frequency + Verb System

## 17. Three Hobby Structures

| Meaning | Structure | Example |
|---|---|---|
| like doing | `lubić + infinitive` | **Lubię czytać.** |
| like something | `lubić + Accusative` | **Lubię kino.** |
| be interested in | `interesować się + Instrumental` | **Interesuję się kinem.** |

> [!IMPORTANT] Memorise this
> **lubić robić** → infinitive  
> **lubić coś** → Accusative  
> **interesować się czymś** → Instrumental

---

## 18. Frequency Ladder

| Frequency | Polish |
|---|---|
| always | **zawsze** |
| every day | **codziennie** |
| usually | **zwykle** |
| often | **często** |
| from time to time | **od czasu do czasu** |
| rarely | **rzadko** |
| never | **nigdy** |

> [!TIP] Order
> **zawsze → zwykle → często → od czasu do czasu → rzadko → nigdy**

---

## 19. Conjugation Families

| Family | `ja` | `ty` | Example |
|---|---|---|---|
| `-m, -sz` | `-m` | `-sz` | czytam, czytasz |
| `-ę, -isz` | `-ę` | `-isz` | mówię, mówisz |
| `-ę, -ysz` | `-ę` | `-ysz` | tańczę, tańczysz |
| `-ę, -esz` | `-ę` | `-esz` | piszę, piszesz |
| `-ować → -uję` | `-uję` | `-ujesz` | studiuję, studiujesz |

## 23. Food → Accusative

| Structure | Example |
|---|---|
