Lecture 2 — Gender + Nominative + -m/-sz verbs

6. Nominative: adjective + noun

Lecture 3 — Nationality/profession + Instrumental

8. To jest vs jest

Structure	Case	Example
To jest + noun	Nominative	To jest Polak.
On jest + adjective only	Nominative	On jest sympatyczny.
On jest + noun	Instrumental	On jest Polakiem.
On jest + adj. + noun	Instrumental	On jest sympatycznym Polakiem.

9. Instrumental singular — Kim? Czym?

	Masculine	Feminine	Neuter
adjective	-ym / -im	-ą	-ym / -im
noun	-em / -iem	-ą	-em / -iem
example	dobrym nauczycielem	dobrą nauczycielką	dobrym dzieckiem

k/g → -im / -iem

10. Instrumental plural

	All genders
adjective	-ymi / -imi
noun	-ami
example	ambitnymi studentami

Exception: dziecko → dziećmi

Lecture 4 — Family + possessives + Accusative

15. Accusative — Biernik: Kogo? Co?

Gender	Adjective	Noun

Examples:

Nominative	Accusative

sympatyczny brat	mam sympatycznego brata

Lecture 5 — Hobby + frequency + verb system

17. Three hobby structures

Meaning	Structure	Example
like doing	lubić + infinitive	Lubię czytać.
like something	lubić + accusative	Lubię kino.
be interested in	interesować się + instrumental	Interesuję się kinem.

18. Frequency ladder

Frequency	Polish

every day	codziennie
usually	zwykle
often	często
from time to time	od czasu do czasu
rarely	rzadko
never	nigdy

19. Conjugation families

Family	ja	ty	Example
-m, -sz	-m	-sz	czytam, czytasz
-ę, -isz	-ę	-isz	mówię, mówisz
-ę, -ysz	-ę	-ysz	tańczę, tańczysz
-ę, -esz	-ę	-esz	piszę, piszesz

20. -ować pattern
