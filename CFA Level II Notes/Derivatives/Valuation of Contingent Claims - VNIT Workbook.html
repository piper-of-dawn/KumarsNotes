The replicating desk

One-period binomial · risk-neutral pricing · arbitrage

Hint. First match the call in both states using shares plus a risk-free cash position. The probability is a pricing weight, not an estimate of the market’s beliefs.

Terminal states. Su = 84(1.30) = 109.20; Sd = 84(0.80) = 67.20. The call pays 19.20 and 0.

Replica. Hedge ratio h = (19.20 − 0)/(109.20 − 67.20) = 0.457143 shares. The time-0 risk-free position B = (0 − h × 67.20)/1.05 = −29.257143, so borrow 29.257143. Call value = h × 84 + B = 9.142857 ≈ 9.14.

Risk-neutral route. π = (1.05 − 0.80)/(1.30 − 0.80) = 0.50; [0.50(19.20) + 0.50(0)]/1.05 = 9.142857. The put is 9.142857 + 90/1.05 − 84 = 10.857143 ≈ 10.86. Neither result needs a real-world probability.

Arbitrage. Write the quoted call for 10.40; buy 0.457143 shares, financed in part by borrowing 29.257143. The replica exactly offsets the short call at expiry. Cash retained today = 10.40 − 9.142857 = 1.257143 ≈ 1.26 per option.

The exercise decision

Two-period European and American options · dividend boundary

Hint. Backward induction uses continuation until an American exercise right makes immediate exercise more valuable. Test the dividend call using the supplied node values; it is a separate case.

Tree and probability. Terminal shares: 156.25, 100.00, 64.00. Call payoffs: 51.25, 0, 0; put payoffs: 0, 5, 41. π = (1.05 − 0.80)/(1.25 − 0.80) = 5/9.

European call. At the up and down time-1 nodes: [(5/9)51.25]/1.05 = 27.1164 and 0. Time-0 call = [(5/9)27.1164]/1.05 = 14.3473 ≈ 14.35.

European put. Time-1 continuation: [(4/9)5]/1.05 = 2.1164 at up; [(5/9)5 + (4/9)41]/1.05 = 20.0000 at down. Time-0 put = [(5/9)2.1164 + (4/9)20]/1.05 = 9.5854 ≈ 9.59.

American put. At up, exercise max(105 − 125, 0) = 0, so continue at 2.1164. At down, exercise 105 − 80 = 25, exceeding continuation 20. Time-0 value = [(5/9)2.1164 + (4/9)25]/1.05 = 11.7018 ≈ 11.70. Early-exercise premium = 2.1164 ≈ 2.12.

Dividend call. Immediate exercise = 116 − 105 = 11 > 9.80, so exercise just before ex-dividend. A non-dividend-paying American call has no corresponding dividend capture and normally should not be exercised early under these assumptions.

A rate tree with moving discount factors

Two-period interest-rate option · state-specific discounting

Hint. A rate option’s underlying rate moves, and the discount rate moves with the node. Roll back one step at a time.

Terminal payoff per USD 1. Call: max(r − 2.50%, 0) = 0.025, 0.005, 0. Put: max(2.50% − r, 0) = 0, 0, 0.015.

Time 1. Call up = [0.5(0.025) + 0.5(0.005)]/1.04 = 0.01442308; call down = [0.5(0.005)]/1.02 = 0.00245098. Put up = 0; put down = [0.5(0.015)]/1.02 = 0.00735294.

Time 0. Call = 2,000,000 × [0.5(0.01442308) + 0.5(0.00245098)]/1.03 = USD 16,382.58. Put = 2,000,000 × [0.5(0) + 0.5(0.00735294)]/1.03 = USD 7,138.78.

Interpretation. At time 1 the up state finances at 4% and the down state at 2%. A uniform 3% discounts a future cash flow at the wrong rate in both states; only the time-0 rollback uses 3%.

The right to fix a swap

Payer and receiver swaptions · annuity scaling · parity

Hint. “Payer” refers to paying the fixed swap rate. Use accrual × PVA once; no separate discount factor is needed.

Position and d terms. The floating-rate borrower buys a payer swaption, allowing it to pay fixed if rates rise. d₁ = [ln(0.036/0.034) + 0.22²/2]/0.22 = 0.369811; d₂ = 0.149811.

Premiums. Payer = USD 20m × 0.5 × 3.70[0.036N(d₁) − 0.034N(d₂)] = USD 154,220.21. Receiver = USD 20m × 0.5 × 3.70[0.034N(−d₂) − 0.036N(−d₁)] = USD 80,220.21.

Parity. Payer − receiver = USD 20m × 0.5 × 3.70(0.036 − 0.034) = USD 74,000.00. Long payer/short receiver is receive-floating/pay-fixed forward swap exposure, which is valuable here because the forward fixed rate exceeds the strike.

Timing and bond link. PVA already discounts the fixed payments, including the swaption life; another e−rT is a second discount. The issuer’s embedded call in a callable fixed-rate bond is economically akin to a receiver swaption sold by the bondholder: it becomes valuable when rates fall.

A hedge that remembers curvature

Delta · gamma · theta · vega · rho · implied volatility

Hint. A short put reverses both its negative delta and its positive gamma. Neutralize gamma with an option first, then repair delta with shares.

Initial exposure. Delta = 1,000(0.58) − 600(−0.41) = +826; gamma = 1,000(0.026) − 600(0.018) = +15.2. Delta-only hedge: short 826 shares.

Two-Greek hedge. Hedge-option units = −15.2/0.040 = −380 options. Its delta is −380(0.35) = −133; residual delta = 826 − 133 = 693, so short 693 shares. Shares have zero gamma. The hedge is local; Greeks change when the share or time changes.

Scenario. Delta-plus-gamma change ≈ 826(3) + ½(15.2)(3²) = +2,546.40. Delta-only gives +2,478.00; the 68.40 gap is the positive curvature term. This is a local Taylor approximation, especially fragile for a USD 3 move.

Other Greeks. Theta = 1,000(−0.012) − 600(−0.010) = −6.00 per day. Vega = 1,000(0.36) − 600(0.29) = +186.00 per volatility percentage point. Rho = 1,000(0.28) − 600(−0.22) = +412.00 per interest-rate percentage point, each holding other inputs fixed.

Implied volatility. Quote exceeds model by 1.20. At 0.36 per vol point, Δσ ≈ 1.20/0.36 = 3.333 percentage points; implied σ ≈ 23.33%. Vega changes with σ, so this is a first-order estimate, not a full BSM inversion. Different strikes and maturities can yield a smile or surface.
